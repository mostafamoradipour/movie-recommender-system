# Contributing

Contributions to the movie recommendation notebooks are welcome.

## Guidelines

- Open an issue before large changes to data sources, feature design, or recommendation methodology.
- Document data provenance, preprocessing, assumptions, and limitations.
- Keep notebooks reproducible and outputs concise. Do not commit large downloaded datasets, API keys, or generated caches.
- Avoid claiming recommendation quality without a clearly described evaluation protocol.

## Pull requests

Create a focused branch and describe the purpose, notebook(s) changed, data requirements, and validation performed. Ensure examples do not expose API keys or other private credentials, and update the README when the workflow changes.
